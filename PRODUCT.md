# PulseTeam Product Document

## Problem
Remote teams face burnout, overload, and disengagement that goes unnoticed until it's too late.

## Solution
PulseTeam gives managers **team-level wellness insights** without invasive monitoring.

## Core features

### 1. Employee Dashboard
- Personal wellness score
- Meeting load
- Focus time
- Wellness nudges
- Privacy controls

### 2. Manager Dashboard
- Team health overview
- Risk scoring
- Trend analysis
- Nudge history
- Action recommendations

### 3. Admin Console
- Privacy settings
- Audit logs (planned)
- Data export
- Integration management
- User management

## Privacy principles
1. **No content capture** — we don't read messages
2. **No keystrokes** — we don't monitor typing
3. **Aggregate first** — team-level data by default
4. **Opt-in nudges** — employees control notifications
5. **Export on demand** — users can download their data

## Integrations (planned)

- Google: meeting load, workspace metadata
- Microsoft: Teams calendar, status
